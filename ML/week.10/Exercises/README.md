# Decision Trees & Random Forests - Kaggle Exercise

Simple exercise to learn Decision Trees and Random Forests by building a Kaggle competition submission.

## Files

- `Exercises_Decision_Trees_RandomForest.ipynb` - Main notebook

## Datasets

### Regression (Exercise 1)
- Download: https://www.kaggle.com/competitions/2022-regression-data-challenge/data
- Save: `data/regression_train.csv`

### Classification (Exercise 2)
- Download: https://www.kaggle.com/competitions/playground-series-s6e10/data
- Save: `data/classification_train.csv` and `data/classification_test.csv`

## How to Use

1. Download datasets from Kaggle links above
2. Create `data/` folder and save CSV files there
3. Open the notebook and follow the TODOs
4. Replace commented code with your implementation
5. Submit your `submission.csv` to Kaggle

## What You'll Learn

- Load and explore data
- Train Decision Trees and Random Forests
- Compare model performance
- Make predictions and prepare submission files
- Submit to Kaggle competitions
